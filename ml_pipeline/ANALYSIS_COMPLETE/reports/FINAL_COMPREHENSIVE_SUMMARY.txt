## SECTION 7: DATA QUALITY RECOMMENDATIONS

### For Model Training

1. **Class Weighting** ⭐ RECOMMENDED
   ```
   Inverse Class Frequency Weighting
   weight[i] = total_images / (num_classes * count[i])
   ```
   - Prevents overrepresented classes from dominating training
   - Balances learning across all disease types

2. **Data Augmentation**
   - Apply for classes with < 500 images (45 classes)
   - Techniques: Rotation, flip, color jitter, zoom
   - Target: Achieve ~1,000-2,000 images per class minimum

3. **Sampling Strategy**
   - Use stratified sampling to maintain class distribution
   - In each batch, ensure proportional class representation
   - Prevents mode collapse to overrepresented classes

4. **Train/Val/Test Split**
   - Use stratified splitting (already in CSV: 'split' column)
   - Maintain class distribution across all sets
   - Recommended: 70% train, 15% val, 15% test

5. **Loss Functions** 
   - Consider Focal Loss for remaining imbalance
   - Alternative: Weighted Cross-Entropy (recommended)
   - Benefit: Better handling of hard examples

6. **Monitoring Metrics**
   - Track per-class precision, recall, F1
   - Use macro-averaged metrics (equal weight to all classes)
   - Monitor minority class performance specifically
